# 本地联调测试手册（2026-06-29）

这份文档用于系统性测试当前本地环境：前端 `5174`、后端 `8003`、Postgres、Redis，以及 P4 智能匹配管理后台。测试目标不是只看页面能不能打开，而是确认关键角色、真实接口、核心业务闭环和 P4 管理能力都能跑通。

## 1. 测试范围

本轮建议测试 5 类内容：

1. 环境和服务健康检查。
2. 求职者端：登录、岗位浏览、匹配详情、简历、投递记录。
3. 招聘者端：登录、企业认证状态、岗位管理、投递和人才池。
4. 管理端：岗位审核、企业认证审核、规则管理、质量看板。
5. P4 智能匹配后台：策略列表、创建、详情、编辑、克隆、离线评估。

不把以下内容作为本轮通过标准：

1. 真实生产环境上线证据。
2. 真实向量召回服务接入效果。
3. 智能策略灰度实验真正影响线上匹配结果。
4. 仍标记为演示或 mock 的页面数据。
