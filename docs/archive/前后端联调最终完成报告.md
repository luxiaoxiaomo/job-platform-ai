## 🔧 修复的阻断问题

### 问题1: 验证码接口方法不匹配 ✅ 已修复

**问题**：
- 后端：POST + query parameter
- 前端：GET + query parameter

**修复**：
```javascript
// 修复后
export async function sendVerificationCode(phone) {
  return post(`/api/v1/auth/send-verification-code?phone=${encodeURIComponent(phone)}`)
}
```

### 问题2: 401跳转不支持HashRouter ✅ 已修复

**问题**：
- 路由：HashRouter
- 跳转：`window.location.href = '/login'`

**修复**：
```javascript
// 修复后
window.location.href = '/#/login'
```

**修复位置**：
- `api.js` - 401错误处理

- `mock.js` - logout()
