# 基础数据标准职位库推进记录

日期：2026-06-19

## 背景

对比 PRD 一期后，后台“基础管理”仍有较多 mock 能力。其中标准职位库属于 P1 基础数据能力，并且 PRD 要求基础数据增改需要记录操作日志。

本轮选择先推进标准职位库，原因：

- 后台已有“标准职位库”入口，但只读取前端 mock 数据。
- 标准职位名称、别名映射是后续 AI 职位标准化、搜索召回和推荐归一化的基础。
- 该能力可独立闭环，不依赖真实微信、真实大模型或外部服务。

- 新增基础数据模块：`app/modules/base_data/`
- 新增标准职位库表：`standard_positions`
