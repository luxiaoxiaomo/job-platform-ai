# 简历解析底座协作看板

本看板用于 Codex 与 Claude Code 在同一个工作目录下协作。任何任务开工前，先确认 Owner 和文件边界，避免两边同时改同一批文件。

## 状态约定

| 状态 | 含义 |
| --- | --- |
| `Todo` | 未开始 |
| `In Progress` | 正在做，只允许 Owner 修改对应文件 |
| `Blocked` | 被依赖、环境或接口阻塞 |
| `Review` | 已完成，等待另一个 AI 或用户检查 |
| `Done` | 已验证完成 |

## Owner 约定

| Owner | 默认职责 |
| --- | --- |
| Codex | 后端、数据库迁移、API contract、后端测试 |
| Claude | 前端页面、交互、浏览器验证、字段映射评审 |
| Both | 需要先对齐 contract，再分别改后端/前端 |

- 没有越界修改对方负责文件。
