# 空岗信息发布对接平台 - 原型演示

## 快速启动

### Windows 用户
双击 `启动原型演示.bat`，浏览器会自动打开 http://localhost:8080

### Mac/Linux 用户
```bash
# 方式 1：使用 Python（系统自带）
python3 -m http.server 8080 -d dist

# 方式 2：使用 Node.js
npx serve -s dist -l 8080
```

然后打开浏览器访问：http://localhost:8080

## 导航指引

### 首页
- 选择进入**应聘者端**、**招聘者端**或**管理后台**

### 应聘者端核心流程
1. **注册** → 上传简历（AI 解析）→ 简历画像
2. **发现岗位**（AI 推荐）→ 人岗匹配分析 → 投递
3. **企业画像**穿透 → 查看企业详情
4. **AI 面试准备** → 生成模拟题
5. **通知中心**（从底部导航「我的」→ 第一项进入）

### 招聘者端核心流程
1. **企业认证**（OCR 识别营业执照）→ 等待审核
2. **发布岗位**（AI 辅助）/ 批量导入 → 等待审核
3. **配置岗位画像** → JD 吸引力分析
4. **人才池**（按人聚合）→ 候选人详情 → 匹配度分析
5. **面试管理**（从「我的」tab 进入）→ 约面试 → 记录反馈
6. **数据统计** + **招聘漏斗**分析
7. **通知中心**（从「我的」→ 第一项进入）

### 管理后台（桌面端全屏）
1. **数据概览** → 用户/岗位趋势
2. **审核管理** → 点击「查看详情」→ 通过/驳回操作
3. **AI 监控** → 各 AI 能力运行状态
4. **用户管理** → 招聘者/应聘者列表
5. **基础数据** → 标准职位库

## 产品亮点

### AI 能力全流程渗透
- 简历解析与画像生成
- 岗位 JD 优化建议
- 人岗智能匹配（双向匹配度）
- 面试题库智能生成
- 内容安全审核（OCR + 合规检测）

### 双端设计
- **应聘者**：微信小程序风格，移动优先
- **招聘者**：微信小程序风格，兼顾桌面操作
- **管理后台**：桌面端全屏，数据可视化

### 数据闭环
- 浏览量穿透（按人聚合，去重展示）
- 招聘漏斗分析（浏览→留言→沟通→面试→录用）
- 团队协作备注 + 跟进提醒

## 技术栈

- **前端框架**：React 18 + React Router
- **构建工具**：Vite
- **样式**：纯 CSS（微信小程序风格）
- **数据**：Mock 数据（src/mock/data.js）

---

## 注意事项

- 这是**静态原型**，所有数据都是模拟数据，不会保存到后端
- 部分交互（如审核操作、面试反馈）会有操作反馈，但不会持久化
- 原型用于产品评审和需求对齐，非最终产品
