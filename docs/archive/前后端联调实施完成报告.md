## ⚠️ 注意事项

### 前端

#### Mock/Real切换
```bash
# 联调模式（连接真实后端）
VITE_USE_MOCK=false
VITE_API_BASE_URL=http://localhost:8001

# 演示模式（使用Mock数据）
VITE_USE_MOCK=true
```

#### Token管理
- Token存储在localStorage
- Key: `access_token`
- 登录/注册自动保存
- 401自动清除并跳转登录

#### 错误处理
- 网络错误：Toast提示
- 401未授权：清除token，跳转登录
- 403无权限：Toast提示
- 其他错误：显示后端返回的detail信息

### 后端

#### CORS配置
确保`.env`中包含：
```
ALLOWED_ORIGINS=["http://localhost:3000","http://localhost:8080","http://localhost:5173","http://localhost:5174","http://localhost:5175"]
```

#### API端点
所有API都在 `/api/v1/` 前缀下：
- `/api/v1/auth/send-verification-code` - 发送验证码
- `/api/v1/auth/register` - 注册
- `/api/v1/auth/login` - 登录
- `/api/v1/users/me` - 当前用户信息
- `/api/v1/users/{id}` - 指定用户信息
