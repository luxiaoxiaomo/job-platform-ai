# 微信真实通知接入准备

日期：2026-06-19

## 当前准备范围

- 用户表已预留微信绑定字段：`wechat_openid`、`wechat_unionid`、`wechat_app_id`、`wechat_bound_at`。
- 通知 push worker 已通过 provider 抽象发送，不再直接把所有任务无条件标记为 sent。
- 默认 `WECHAT_PUSH_MODE=dry_run`，不会真实调用微信，但会写入 provider 元数据。
- `WECHAT_PUSH_MODE=live` 时会检查用户是否已绑定 `wechat_openid`、模板 ID 和服务号凭据。
- 真实发送失败会记录到 `notification_push_tasks.error_message` 和 payload 的 `push_provider`。
- `attempt_count` 已加入任务表，为后续失败重试策略做准备。

## 后续切 live 前需要补齐

1. 在微信公众平台申请服务号模板消息。
2. 配置 `.env`：

```env
WECHAT_PUSH_MODE=live
WECHAT_APP_ID=
WECHAT_APP_SECRET=
WECHAT_TEMPLATE_ACTION_BASE_URL=
WECHAT_TEMPLATE_DEFAULT=
WECHAT_TEMPLATE_JOB_REVIEW=
WECHAT_TEMPLATE_MESSAGE=
WECHAT_TEMPLATE_APPLICATION=
WECHAT_TEMPLATE_APPLICATION_STATUS=
WECHAT_TEMPLATE_MATCH=
```

3. 接微信 OAuth/授权绑定，把用户的服务号 `openid` 写入 `users.wechat_openid`。
4. 用测试号先跑 `notifications/admin/push-tasks/run-worker` 验证模板参数和跳转 URL。

## 当前限制

- 尚未实现微信 OAuth 回调和用户绑定接口。
- 尚未按每个正式模板精细化字段名，当前 provider 默认输出通用 `first/keyword1/keyword2/remark`。
- live 模式下未绑定 openid 的用户会保留站内通知，外部 push task 标记为 failed。
