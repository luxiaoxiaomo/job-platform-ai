## 五、常见问题排查

| 现象 | 可能原因 | 解决 |
|------|---------|------|
| 画像页一直"加载中…" | API 返回 500 或超时 | F12 看 Network，检查后端日志 |
| 画像页显示"还未上传简历" | API 返回 `resume: null` | 检查数据库 seeker_resumes 表是否有数据 |
| 基础信息全是空 | `basic_info` 为 null | 确认是否已点"确认并保存"投影到 resume_basic_infos |
| 技能/教育/工作等不显示 | `summaries` 数组为空 | 确认是否已投影到对应明细表 |
| 完整度显示 0% | 计算逻辑问题或数据未投影 | 检查后端 completeness 计算逻辑 |
| 投递页"暂未生成" | 投影后未回写到明细表 | 确认 confirm 接口是否调用成功 |
