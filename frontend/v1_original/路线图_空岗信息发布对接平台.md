# 产品路线图规划报告：空岗信息发布对接平台

**文档版本**：v1.0
**规划起始时间**：2026年Q3
**规划结束时间**：2027年Q2
**制定日期**：2026年6月2日
**对标产品**：剑鱼标讯、BOSS直聘、猎聘、脉脉

---

## 一、产品愿景与战略目标

空岗信息发布对接平台致力于打造一款以微信生态为核心入口的轻量级招聘对接工具，通过降低招聘方与求职者的信息不对称、简化发布与匹配流程，为中小企业和基层求职者提供真实、高效、低门槛的岗位信息撮合服务。平台以"真实岗位、精准对接、极简体验"为核心价值主张，一期聚焦MVP验证核心招聘闭环，二期通过AI智能化和画像匹配提升对接效率，三期构建人力资源服务生态实现商业化变现，最终成为区域性招聘市场的基础设施级平台。

### 里程碑详细说明

#### M1：一期MVP核心功能（2026年7月 ~ 2026年9月）

**目标**：验证核心招聘闭环，实现"发布-浏览-沟通"基础链路。

**关键交付物**：
- 微信授权登录与手机号获取模块
- 招聘者注册认证流程（单位信息管理、真实名+虚拟名体系）
- 应聘者注册认证流程（实名/虚拟名）
- 空岗信息发布模块（岗位名称、工作城市、薪资待遇、工作职责模板、任职要求模板）
- 企业认证流程（营业执照上传、统一社会信用代码验证）
- 岗位信息审查机制（平台人工审核）
- 职位浏览与详情查看（含个人信息补充触发）
- 关键词订阅与消息推送
- 留言互动与对话功能
- 简历查看（招聘者端）
- 职位收藏（应聘者端）
- 转发推荐功能
- 数据统计基础模块（招聘者端）
- 双端个人主页

**依赖条件**：
- 微信开放平台小程序/服务号审核通过
- 企业营业执照OCR识别服务接入
- 云存储与图片CDN服务开通
- 基础服务器与数据库环境搭建

#### M2：二期智能化+精准化（2026年10月 ~ 2026年12月）

**目标**：通过AI能力提升信息质量与匹配效率，构建差异化竞争优势。

**关键交付物**：
- 天眼查企业信息印证与自动填充
- 单位标签体系与岗位标签体系
- 岗位画像模型构建
- JD智能化（AI代写 + 结构化解析）
- 关键词搜索功能（双向：招聘者搜应聘者、应聘者搜职位）
- 画像匹配精准推送引擎
- 应聘者比较分析功能
- 面试安排与通知（系统通知 + 邮件模板）
- 测评考试链接接入
- AI面试链接接入
- 在线简历上传与AI优化
- 简历解析与结构化存储
- 自动打标签系统
- 人脸识别认证
- 隐私保护（屏蔽指定人/公司）
- 用人单位点评功能
- 数据统计分析增强

**依赖条件**：
- 一期稳定运行且用户数据达到一定规模（建议最低5,000注册招聘者、20,000注册应聘者）
- AI文本生成服务接入（如通义千问/GPT等）
- 天眼查企业信息API授权
- 人脸识别SDK接入（如腾讯云慧眼）
- 简历解析引擎部署

#### M3：三期生态化+商业化（2027年1月 ~ 2027年4月）

**目标**：构建人力资源服务生态，开启商业化变现通道。

**关键交付物**：
- 大数据分析平台（行业年度分析报告、招聘职位分析、应聘者分析）
- 简历完整度评分系统
- 个人竞争力分析工具
- 增值服务商城（简历优化、职位信息优化、面试培训、猎头服务、面试考官提供）
- 外部产品服务管理（人才测评、AI面试考试、培训课程）
- 社区互动模块（行业新闻动态、朋友圈、乙方厂商点评）
- 投诉与举报系统
- 有偿广告系统（公号软文、乙方招聘信息广告位）
- 运营推广工具（自媒体内容管理、市场活动管理、地推链接追踪、平台代理发布）
- 平台管理体系完善（微信服务号运营、会员管理、基础管理、费用管理、平台规则）

**依赖条件**：
- 平台数据积累达到分析阈值（建议最低50,000条岗位数据、100,000份简历数据）
- 支付系统上线（微信支付商户号）
- 运营团队与内容团队就位
- 合作伙伴（猎头、培训机构、测评机构）签约

## 十、路线图健康度评分框架

### 10.1 健康度评估维度

建立以下六个核心维度，每月进行一次健康度评估，每项1-5分（5分最优），总分30分。

| 维度 | 评估标准 | 权重 |
|------|----------|------|
| **进度健康度** | 里程碑按计划推进的完成度 | 20% |
| **需求稳定性** | 需求变更频率与范围 | 15% |
| **资源充足度** | 人力、预算、基础设施是否满足 | 20% |
| **风险可控度** | 已识别风险的缓解进展 | 15% |
| **质量达标度** | Bug率、用户满意度、技术指标 | 15% |
| **商业对齐度** | 功能交付与商业目标的匹配度 | 15% |

### 10.2 健康度评分细则

#### 进度健康度（1-5分）

| 分数 | 标准 |
|------|------|
| 5 | 所有里程碑均按计划完成或提前 |
| 4 | 80%以上里程碑按计划完成，偏差<1周 |
| 3 | 60%-80%里程碑按计划完成，偏差1-2周 |
| 2 | 40%-60%里程碑按计划完成，偏差2-4周 |
| 1 | 低于40%里程碑按计划完成，偏差>4周 |

#### 需求稳定性（1-5分）

| 分数 | 标准 |
|------|------|
| 5 | Sprint内需求变更率<5% |
| 4 | Sprint内需求变更率5%-10% |
| 3 | Sprint内需求变更率10%-20% |
| 2 | Sprint内需求变更率20%-35% |
| 1 | Sprint内需求变更率>35% |

#### 资源充足度（1-5分）

| 分数 | 标准 |
|------|------|

| 4 | 关键岗位到位，预算满足，基础设施基本就绪 |
| 3 | 存在1-2个关键岗位空缺，预算紧张 |
| 2 | 多个关键岗位空缺或预算不足 |
| 1 | 资源严重不足，项目无法正常推进 |

| 1 | 多个重大风险未处理，已影响项目 |
