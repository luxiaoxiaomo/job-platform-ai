## 📝 技术方案说明

### Alembic ENUM修复

**之前的问题**：
```python
# 手动创建（第一次）
op.execute("""
    DO $$ BEGIN
        CREATE TYPE user_role AS ENUM ('seeker', 'recruiter', 'admin');
    END $$;
""")

# sa.Enum自动创建（第二次）
sa.Column('role', sa.Enum(..., create_type=False), ...)
```

**修复后**：
```python
from sqlalchemy.dialects import postgresql

# 只创建一次，让SQLAlchemy管理
sa.Column('role', postgresql.ENUM('seeker', 'recruiter', 'admin', 
                                   name='user_role', create_type=True), ...)
```

### pytest修复

**之前的问题**：
- asyncpg连接池在Windows + pytest-asyncio下有已知bug
- "cannot perform operation: another operation is in progress"

**修复方案**：
```python
# 使用SQLite进行测试（避免asyncpg问题）
TEST_DATABASE_URL = "sqlite+aiosqlite:///:memory:"

test_engine = create_async_engine(
    TEST_DATABASE_URL,
    echo=False,
    connect_args={"check_same_thread": False}
)
```

**优势**：
- ✅ 测试速度快（内存数据库）
- ✅ 无需依赖PostgreSQL服务
- ✅ 避免Windows asyncpg问题
- ✅ 完全隔离的测试环境

**注意**：
- 生产环境仍使用PostgreSQL
- SQLite仅用于单元测试
- PostgreSQL特有功能需在集成测试验证
