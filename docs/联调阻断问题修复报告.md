## 🔴 发现的阻断问题

### 问题1: 验证码接口方法不匹配

**问题描述**：
- **后端**：`@router.post("/send-verification-code")` - POST方法，query parameter
- **前端**：`get('/api/v1/auth/send-verification-code', { phone })` - GET方法

**影响**：
- 注册流程第一步"发送验证码"直接失败
- 405 Method Not Allowed错误

**修复方案**：
```javascript
// 修复前
export async function sendVerificationCode(phone) {
  return get('/api/v1/auth/send-verification-code', { phone })
}

// 修复后
export async function sendVerificationCode(phone) {
  return post(`/api/v1/auth/send-verification-code?phone=${encodeURIComponent(phone)}`)
}
```

**修复文件**：
- ✅ `src/services/auth.js`
- ✅ `src/services/mock.js`

---

### 问题2: 401跳转不支持HashRouter

**问题描述**：
- **路由模式**：使用HashRouter（`main.jsx`）
- **跳转代码**：`window.location.href = '/login'`
- **问题**：跳转到根路径而非hash路由

**影响**：
- Token失效时跳转失败
- 用户无法正确跳转到登录页

**修复方案**：
```javascript
// 修复前
window.location.href = '/login'

// 修复后
window.location.href = '/#/login'
```

**修复文件**：
- ✅ `src/services/api.js` - 401错误处理
- ✅ `src/services/auth.js` - logout()方法
- ✅ `src/services/mock.js` - logout()方法
