# P4 智能匹配任务包

## 1. 使用说明

本文把 `P4_智能匹配_MVP_PRD.md` 和 `P4_智能匹配_接口契约与算法边界.md` 拆成可独立执行、验证和回滚的工程任务包。

执行原则：

- 先完成数据契约和审计底座，再接入召回/评分，再做前端观察和灰度。
- 每个任务独立提交、独立验收、独立回滚。
- 默认不改变线上规则 baseline。
- demo/mock 只能用于联调和演示，不能作为上线证据。

## 2. 后端任务

### BE-P4-01 智能策略数据模型与迁移

Description: 新增智能策略、离线评估、评估样本/结果的最小数据结构。

Dependencies: T004 contract approved.

Acceptance Criteria:

- [OK] 迁移创建 strategy/evaluation 相关表或等价持久化结构。
- [OK] strategy 支持 `draft/evaluating/testing/active/archived` 状态。
- [OK] 表结构记录 base_rule_config_id、vector_recall、hybrid_weights、fallback_policy、created_by、timestamps。
- [OK] 迁移可重复执行，现有 P3 表不被破坏。

Verification Method:

- Run targeted backend tests for model creation and status transitions.

### BE-P4-04 向量召回适配层

Description: 增加可开关的 vector recall adapter。P0 可先用本地可替换接口或空实现，必须保留降级路径。

### BE-P4-05 混合评分服务
