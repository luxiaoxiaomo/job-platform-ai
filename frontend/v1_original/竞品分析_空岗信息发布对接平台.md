## 1. 我方产品概要

### 1.1 产品定位

**空岗信息发布对接平台**——基于微信生态的空岗信息发布与对接平台，聚焦招聘者与应聘者的双向精准匹配，以"轻量化、智能化、隐私友好"为核心价值主张。

### 1.2 核心功能体系

| 角色 | 核心功能 |
|------|---------|
| **招聘者端** | 微信认证注册、单位信息管理、空岗信息填写发布（含AI代写JD）、企业认证、消息互动、简历查看、数据统计 |
| **应聘者端** | 微信认证注册、关键词订阅、职位推送、简历上传（AI优化）、精准匹配、在线投递、留言对话 |

### 1.3 差异化特色

- **标签体系**：单位标签 / 岗位标签 / 简历标签，构建多维画像
- **画像模型**：基于标签与行为数据的双向画像匹配
- **AI智能化**：AI代写JD、AI简历优化、智能推荐
- **隐私保护**：虚拟名机制，保护求职者在职信息
- **微信生态**：无需下载APP，依托微信小程序实现轻量化使用

### 1.4 三期规划路线

| 阶段 | 重点内容 |
|------|---------|
| 一期 | 基础招聘对接功能 + AI代写/优化 |
| 二期 | 大数据分析 + 增值服务（简历优化/面试培训/猎头） |
| 三期 | 社区互动 + 职场生态 |

## 8. 竞争定位矩阵（四象限图）

### 8.1 维度选取

- **X轴：产品形态轻重度**（左轻右重）
  - 轻 = 小程序/轻应用，无需安装，即用即走
  - 重 = 独立APP，功能全面，深度使用
- **Y轴：目标用户覆盖面**（下窄上广）
  - 窄 = 聚焦特定群体/行业/区域
  - 广 = 全行业全人群覆盖

### 8.2 四象限分布

```
         用户覆盖面广
              ↑
              │
    ┌─────────┼────────────┐
    │         │            │
    │  脉脉   │  BOSS直聘   │
    │ (社交+  │  (全行业    │
    │  招聘)  │   全人群)   │
    │         │            │
    │         │   猎聘      │
    │         │  (中高端    │
    │         │   全行业)   │
────┼─────────┼────────────┼────→ 产品形态重
    │         │            │
    │ ★我方   │            │
    │(微信生态│            │
    │ 空岗对接)│            │
    │         │            │
    │ 剑鱼标讯│            │
    │(招投标  │            │
    │ 信息)   │            │
    │         │            │
    └─────────┼────────────┘
              │
         用户覆盖面窄
         产品形态轻
```

### 8.3 象限分析

| 象限 | 特征 | 代表产品 | 分析 |
|------|------|---------|------|
| **左上（轻+广）** | 轻量入口、广泛覆盖 | 脉脉 | 轻量社交切入，覆盖面广但招聘深度不足 |
| **右上（重+广）** | 全功能、全人群 | BOSS直聘、猎聘 | 成熟平台的主阵地，功能完善但使用门槛高 |
| **左下（轻+窄）** | 轻量入口、精准聚焦 | **我方**、剑鱼标讯 | 聚焦特定场景，以轻便和精准取胜 |
| **右下（重+窄）** | 重度产品、窄众市场 | （当前空白） | 此象限商业价值有限 |

### 8.4 我方定位策略

我方占据**左下象限（轻+窄）**的核心位置，策略路径为：

1. **短期**：在左下象限深耕，以"微信生态+空岗对接"做精做透
2. **中期**：沿Y轴向上扩展用户覆盖面（更多行业、更多区域），但保持产品轻量化
3. **长期**：向右上象限渗透（丰富功能+扩展人群），但以小程序为主要载体，保持"轻"的差异化

### 10.4 创新层（Innovate）——行业内尚无，我方首创或领先

> 这些是我方的创新特色，可在市场中形成独特定位。

| 创新项 | 行业现状 | 我方创新 | 风险与应对 |
|--------|---------|---------|-----------|

| **标签画像双向匹配模型** | BOSS/猎聘的AI匹配为黑盒模式，用户无法理解和控制匹配逻辑 | 基于显性标签+隐性行为构建双向画像，匹配逻辑透明可控 | 风险：冷启动标签不足。应对：注册引导填写+AI自动标签提取 |
| **微信社交裂变招聘** | 各平台依赖站内流量和广告投放获客 | 利用微信社交链实现"老带新""职位裂变""社群招聘" | 风险：过度分享可能被微信限制。应对：遵循微信生态规则，设计合理的分享激励 |
| **AI+人工协同JD生成** | AI生成的JD缺乏企业个性化信息 | AI生成基础JD + 引导HR补充企业特色信息，兼顾效率和个性化 | 风险：HR不愿手动补充。应对：AI自动抓取企业公众号/官网信息补充 |
