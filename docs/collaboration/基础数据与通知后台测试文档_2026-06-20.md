## 手工测试流程

### 1. 管理后台进入

1. 打开 `http://127.0.0.1:5174/#/login`。
2. 使用管理员账号登录。
3. 打开 `http://127.0.0.1:5174/#/admin`。
4. 确认顶部显示管理员信息，左侧有“基础数据概览”“标准职位库”“标签库”“匹配规则”“推送队列”入口。

预期：

- 能进入后台。
- 若未登录或 token 失效，会跳转登录。

### 2. 标准职位库

进入后台左侧“标准职位库”。

新增标准职位：

- 标准名称：`后端工程师`
- 分类：`技术研发`
- 别名：`后端开发, 服务端工程师`
- 状态：`启用`
- 说明：任意文本

预期：

- 点击“新增职位”后表格出现新记录。
- 别名按逗号拆分展示。
- 总数增加。

编辑标准职位：

- 点击“编辑”。
- 修改分类为 `互联网技术`。
- 修改别名为 `后端研发, 服务端研发`。
- 保存。

预期：

- 表格内容更新。
- 页面无报错。

停用/启用：

- 点击“停用”。
- 确认状态变为“停用”。
- 再点击“启用”。
- 确认状态恢复“启用”。

重复校验：

- 再新增同名 `后端工程师`。

预期：

- 接口返回重复名称错误。
- 前端 toast 显示保存失败或错误信息。

### 3. 标签库

进入后台左侧“标签库”。

新增父级标签：

- 标签名称：`编程语言`
- 分类：`skill`
- 父级：无父级
- 颜色：`#2563eb`
- 排序：`1`
- 状态：启用

预期：

- 标签库表格新增 `skill / 编程语言`。
- 颜色列显示色块。

新增子标签：

- 标签名称：`Python`
- 分类：`skill`
- 父级：选择 `skill / 编程语言`
- 颜色：`#16a34a`
- 排序：`10`

预期：

- `Python` 出现在标签库。
- 父级列显示 `编程语言`。

编辑标签：

- 编辑 `Python`。
- 修改名称为 `Python 3`。
- 修改排序为 `20`。
- 保存。

预期：

- 名称和排序更新。

停用/启用：

- 点击 `Python 3` 的“停用”。
- 状态变为“停用”。
- 再点击“启用”。
- 状态恢复“启用”。

重复校验：

- 在同分类 `skill` 下再新增 `Python 3`。

预期：

- 接口返回同分类同名错误。
- 前端 toast 显示保存失败或错误信息。

### 4. 操作日志后台页

进入后台左侧“操作日志”。

筛选验证：

- 点击“全部”。
- 点击“标准职位”。
- 点击“标签”。
- 点击“刷新”。

预期：

- 新增、编辑、停用操作都有日志。
- 动作列显示“新增”“更新”“停用”。
- 资源列显示标准职位或标签及对应 ID。
- 变更前 / 变更后能看到关键字段快照。

### 5. 推送队列后台

进入后台左侧“推送队列”。

验证：

- 切换状态筛选：全部、待发送、延后、摘要占位、已发送、失败。
- 点击“刷新”。
- 如存在任务，尝试“标记已发送”或“标记失败”。

预期：

- 列表按状态刷新。
- 标记后状态变化。
- 当前不会真实调用微信，真实微信发送需后续配置公众号/小程序模板消息能力。

## API 快速冒烟

登录获取 token 后，可用接口文档或 curl 测：

```text
GET /api/v1/base-data/standard-positions
POST /api/v1/base-data/standard-positions
PUT /api/v1/base-data/standard-positions/{position_id}

GET /api/v1/base-data/tags
POST /api/v1/base-data/tags
PUT /api/v1/base-data/tags/{tag_id}

GET /api/v1/base-data/operation-logs
```

权限预期：

- admin：允许访问。
- seeker / recruiter：返回 403。
