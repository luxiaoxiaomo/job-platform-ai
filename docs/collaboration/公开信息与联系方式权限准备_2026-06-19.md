# 公开信息与联系方式权限准备（2026-06-19）

## 背景

对齐 PRD 一期里“企业可选择公开信息、求职者可控制联系方式、双方交换联系方式后仍需按授权字段展示”的要求。本次先完成后端数据模型、接口响应和交换逻辑，为后续微信真实通知和前端设置页接入做准备。

## 已完成

- 岗位新增公开策略字段：
  - `company_display_mode`: `display_name` / `company_name` / `anonymous`
  - `contact_phone_public`
  - `contact_email_public`
  - `contact_wechat_public`
- 岗位创建/更新/响应已支持上述字段。
- 岗位公开详情 `public_contact` 按企业认证和公开开关输出企业名、电话、邮箱。
- 求职者资料新增 `email`、`wechat`、`email_public`、`wechat_public`。
- 联系方式交换改为字段级授权：
  - 求职者创建 profile 后，电话、邮箱、微信分别按 `*_public` 输出。
  - 招聘方电话、邮箱按岗位公开开关输出。
  - 企业名称只在岗位选择 `company_name` 且企业认证通过时输出。
  - 匿名模式下招聘方显示为“认证企业”。
- 前端招聘方发布审核页已接入企业名称展示模式、企业邮箱/电话/微信公开开关，并随岗位提交写入后端。
- 前端招聘方岗位详情页已接入已发布岗位公开策略编辑，保存时只更新公开字段，不触发重新审核。
- 前端求职者资料编辑页已接入邮箱、微信和手机/邮箱/微信等公开开关。
- 企业认证新增 `applicant_wechat` 作为招聘方微信来源；岗位 `contact_wechat_public` 打开且认证通过后，公开详情和联系方式交换会返回招聘方微信。
- 前端企业认证表单已接入申请人微信字段。
- 新增 Alembic 迁移：
  - `backend/job-platform/alembic/versions/t9c1e2f3a708_add_public_contact_visibility.py`
  - `backend/job-platform/alembic/versions/u0d2f4a6b809_add_company_certification_wechat.py`
